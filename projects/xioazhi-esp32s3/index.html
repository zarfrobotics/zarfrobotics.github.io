// WHY CLOUD AI?
Running a Large Language Model on a microcontroller is not feasible — LLMs need gigabytes of RAM and heavy compute. Xiaozhi's architecture is clever: the ESP32-S3 handles only the real-time I/O (mic, speaker, display, WiFi), while the cloud handles ASR, the LLM conversation, and TTS synthesis. Round-trip latency is typically under 1.5 seconds on a good connection. This means you get genuine GPT-level intelligence in a device you can hold in your hand for under $10 in components.

FEATURES

🗣️
REAL-TIME VOICE INPUT
INMP441 I2S mic delivers crisp digital audio directly to ESP32-S3. No analog-to-digital conversion needed on the MCU side — noise-free capture for reliable ASR.
🧠
CLOUD AI (DEEPSEEK / GPT)
Xiaozhi platform supports multiple LLM backends including DeepSeek and GPT. The ESP32 just handles transport — the AI model runs server-side with full contextual memory per session.
📺
ST7789 COLOR DISPLAY
240×240 IPS LCD shows pairing code on boot, conversation transcript, animated waveform while talking, and connection status. Full color at 65K color depth.
🔗
PAIRING CODE SYSTEM
On first boot, the device shows a 6-digit pairing code on the ST7789 display. Enter it at xiaozhi.fun to link the device to your AI account — no config file edits needed.
⚡
1.5s RESPONSE LATENCY
ESP32-S3's dual-core LX7 at 240MHz handles audio I/O efficiently. With a stable WiFi connection, full voice-to-voice round trip completes in roughly 1.5 seconds.
🔊
CLASS-D AUDIO OUTPUT
MAX98357A receives I2S data directly from ESP32-S3, no external DAC required. 3.2W into 4Ω for surprisingly loud, clear speech playback from a tiny module.
📡
WEBSOCKET STREAMING
Audio is streamed bidirectionally over WebSocket — mic audio goes up, TTS audio comes down. Real-time full-duplex communication keeps latency low.
🏠
HOME ASSISTANT READY
Xiaozhi supports MQTT and HomeAssistant integration — your voice assistant can control smart home devices, query sensors, and trigger automations through conversation.
🔓
ONE-CLICK BROWSER FLASH

⚠ BREADBOARD LAYOUT TIP
ESP32-S3 DevKitC-1 is 18 pins wide and spans both breadboards when placed in the center gap. Orient it with USB-C port facing away from you. All GPIO headers are accessible on both sides of the two boards.
⚠ 3.3V ONLY FOR MIC + DISPLAY
INMP441 and ST7789 are strictly 3.3V components. Connecting them to the 5V rail will permanently damage both modules. Double-check VCC connections before powering on.
// I2S BUS SEPARATION
Mic (I2S RX) and amplifier (I2S TX) use separate GPIO groups. This is intentional — the ESP32-S3 has two independent I2S peripherals (I2S0 and I2S1), allowing simultaneous full-duplex audio.

SETUP GUIDE

01
ASSEMBLE THE HARDWARE
Place both breadboards side by side and seat the ESP32-S3 DevKitC-1 spanning the center gap. Wire INMP441, MAX98357A, ST7789, and the LED following the pin table above. Use color-coded wires — red for 3.3V, black for GND, and distinct colors for each I2S bus.
02
FLASH THE FIRMWARE
Scroll down to the Flash Tool section. Connect the ESP32-S3 via USB-C to your PC. Open Chrome or Edge — Web Serial is not supported in Firefox or Safari. Click ⚡ CONNECT & FLASH. The firmware is pre-configured for Xiaozhi; you only need to set up WiFi and pair after flashing.
03
CONFIGURE WiFi
On first boot the ST7789 shows a QR code or prompts for network config. Connect to the ESP32's temporary hotspot (Xiaozhi-XXXX) from your phone or PC, navigate to 192.168.4.1, and enter your WiFi credentials. The device will reboot and connect automatically.
04
PAIR WITH XIAOZHI ACCOUNT
Once on WiFi, the ST7789 display shows a 6-digit pairing code. Visit xiaozhi.fun, create a free account, and enter the pairing code to link your device. You can then select the AI model (DeepSeek, GPT, etc.) from the web console.
05
START TALKING
Wake the device by saying the wake word (default: "小智" / "Xiaozhi" or configurable). The LED lights up, the display shows the waveform animation, and you'll hear the AI respond through your speaker within about 1–2 seconds. That's it — your AI voice assistant is live.

BROWSER FLASH TOOL

XIAOZHI AI — ESP32-S3 FIRMWARE FLASHER v1.0
WEB SERIAL
STEP 01
CONNECT YOUR ESP32-S3
Plug the ESP32-S3 DevKitC-1 into your PC via the USB-C port. Use Chrome or Edge — Firefox doesn't support Web Serial API. Make sure no other serial monitor (Arduino IDE, etc.) is open on the same port.

If the device doesn't appear in the port list, hold the BOOT button while plugging in USB to enter download mode.
STEP 02
FIRMWARE IS PRE-LOADED
The Xiaozhi firmware for ESP32-S3 with ST7789 display support is already bundled with this page as firmware/xiaozhi-esp32s3.bin. No need to download or configure anything — the flasher picks it up automatically.

Chip family is locked to ESP32-S3. Flash offset is 0x0000 (merged firmware).
STEP 03
CLICK CONNECT & FLASH
Hit the button on the right. A browser popup will ask you to select the serial port — pick your ESP32-S3. The flasher will erase the chip, then write the firmware. The whole process takes about 30–60 seconds.

After flashing completes, the device reboots automatically into the Xiaozhi firmware. Watch the ST7789 for the WiFi setup screen.
