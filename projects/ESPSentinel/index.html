FEATURES

📺
30fps MJPEG STREAM
Live 640×480 VGA stream over WiFi on port 81. Multipart MJPEG boundary protocol — compatible with any browser and VLC.
🎥
AVI RECORDING TO SD
15fps AVI segments recorded to MicroSD automatically. 1-minute rotation. Byte-exact AVI header with patched frame count and FPS. Stop/start via web UI.
🕹️
PAN / TILT SERVO
Pan on GPIO12, tilt on GPIO13. D-pad + slider control in web UI. 500–2500 µs pulse range for SG90/MG90S. Attach after SD init to avoid boot strapping issue.
👁️
PIR MOTION DETECTION
HC-SR501 on GPIO2. Triggers auto-snapshot saved to SD with timestamped filename. Motion log and event counter in web UI. Toggle on/off at runtime.
📸
SNAPSHOT (SAVE + DOWNLOAD)
Save snapshots to SD with timestamped paths. Download directly to PC from browser. Day/hour folder structure auto-created on SD.
💡
LED FLASH PWM
GPIO4 flash LED with 0–255 PWM brightness control via LEDC. Stays LOW during SD init to avoid clock conflicts on some AI Thinker revisions.
🗂️
SD FILE BROWSER
Browse, preview, download and delete videos/photos directly from the web UI. Folder tree navigation. In-browser AVI playback and JPEG viewer.
🌙
NIGHT MODE + IMAGE SETTINGS
Software night mode (boost gain, brightness, desaturate). Live quality, brightness, contrast, saturation, mirror and flip sliders. All applied in real-time via /camset endpoint.
🌡️
CHIP TEMPERATURE
Live internal chip temperature via ESP32's temperatureRead() sensor. Displayed prominently in status sidebar with colour-coded warning thresholds (55°C / 70°C).

⚠ GPIO12 — STRAPPING PIN
If GPIO12 is HIGH at boot, SD gets 1.8V and won't init. Pan servo MUST be attached only after SD_MMC.begin() returns successfully.
⚠ GPIO4 — LED + SD CLK CONFLICT
GPIO4 is both the flash LED and SD_MMC CLK on some AI Thinker revisions. Always keep LED LOW (off) before and during SD init. Use LEDC PWM only after SD is confirmed ready.
💡 FLASHING ESP32-CAM
Connect FTDI TXD→RXD0, RXD→TXD0, GND→GND, 3.3V→3.3V. Bridge GPIO0→GND before powering to enter flash mode. Remove bridge after upload and press reset.

API ENDPOINTS

// PORT 81 — STREAM SERVER
GET /stream 30fps MJPEG multipart live stream. Open in browser or VLC. :81
GET /snapshot Download single JPEG frame directly to PC. :81
// PORT 82 — CONTROL SERVER
GET / Serves web control panel (ESPSentinel.html from Browser). :82
GET /status JSON: name, IP, recording, pan, tilt, SD, uptime, RSSI, snaps, temp. :82
GET /servo?pan=90&tilt=45 Move pan/tilt servos. Both params optional, 0–180°. :82
GET /led?state=128 Flash LED PWM brightness 0–255. 0 = off. :82
GET /record?cmd=stop|start Stop or restart AVI recording. Returns JSON status. :82
GET /savesnap Save JPEG snapshot to SD. Returns path in JSON. :82
GET /camset?quality=12&brightness=1 Adjust image settings live. Supports quality, brightness, contrast, saturation, hmirror, vflip, nightmode. :82
GET /pir Returns current PIR sensor state as JSON boolean. :82
GET /sd/list?path=/videos JSON array of files/folders at given SD path. :82
GET /sd/download?path=/... Stream SD file as attachment for browser download. :82
GET /sd/delete?path=/... Delete a file from SD. Returns JSON ok status. :82

// HOW TO FLASH & DEPLOY
01 Clone repo or download ZIP from GitHub. Open ESPSentinel.ino in Arduino IDE.
02 In Board Manager, install ESP32 by Espressif. Select board: AI Thinker ESP32-CAM.
03 Install libraries via Library Manager: ESP32Servo, ArduinoJson.SD_MMC is built-in.
04 Edit WIFI_SSID and WIFI_PASS at the top of the sketch with your network credentials.
05 Insert your ESP32-CAM to its MB Board
06 Upload sketch via Arduino IDE. Check Serial Monitor (115200 baud) for IP address.
07 Open ESPSentinel.html in any Browser
